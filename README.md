## About

I'm a security researcher and DevOps engineer who likes working close to the metal — kernel internals, syscalls, and the eBPF layer where visibility either gets built or gets hidden. I split my time between offense (breaking things in lab environments to understand them) and defense (building the detection that catches what I just broke), then wrap it in infrastructure that's automated and observable end to end.

- 🔬 Researching eBPF-based kernel stealth & visibility manipulation — syscall tracing, kprobes, memory forensics
- 🛡️ Practicing controlled exploitation in lab environments — privilege escalation, web, Active Directory, binaries
- 🚨 Building detection engineering skills — SIEM rules, YARA signatures, behavioral alerting, threat hunting
- 🏁 Active CTF competitor, currently working toward CompTIA Security+
- ✅ All research is authorized, scoped, and documented

## About

I work at the intersection of kernel research, offensive security, and DevOps automation — building infrastructure that's observable, pipelines that ship securely, and tooling that surfaces what attackers try to hide.

- 🔬 Researching eBPF-based kernel stealth and visibility manipulation (syscall tracing, kprobes, memory forensics)
- 🛡️ Practicing controlled exploitation in lab environments — privilege escalation, web, Active Directory, binary exploitation
- 🚨 Building detection engineering skills — SIEM rules, YARA signatures, behavioral alerting, threat hunting
- 📄 Writing structured findings reports with remediation guidance
- ✅ All research is authorized, scoped, and documented
